## Recommended fantasy: Ocean Ranger Team

- Same side only. Shared reef health / missions. Personal Marinepedia + cosmetics.
- Light **loadouts** (Spotter / Rescue / Cleaner / Builder) — not evil factions.
- Antagonists = **gear, litter, ghost nets, anchors, plastic surges** (and cartoon “careless boat”), never playable cruelty.

### Dive Budget (kid-safe air)

- Friendly gauge (green → yellow → “time to surface”).
- Surface / buoy / boat = full refill.
- **No drowning death** — soft assist to surface if empty.
- Co-op: buddy nearby slows drain; one “bubble share” boost.
- Deep zones cost more air (gentle real-world teach).

### Example 2-player missions

1. **Ghost Net Lift** — one holds/calms, one frees turtle  
2. **Anchor Off the Reef** — one winches, one frees chain + plants coral  
3. **Manta Corridor** — one clears plastic lane, one guides manta with markers  

### Social model (birthday)

- **Private join code / link**, 2–4 rangers, no stranger matchmaking  
- Emotes/pings first; no open chat required  
- Progress stays on each device’s local profile for MVP  

### Tech (agent consensus)

- **Host-client + WebSocket relay** (e.g. PartyKit) — not pure WebRTC for iPad/school WiFi  
- Sync: poses, mission phase, interactable IDs  
- Local: fish AI, particles, quality tier  
- **~1–2 weeks** for “Buddy Dive” after solo is solid; roles = multi-sprint later
