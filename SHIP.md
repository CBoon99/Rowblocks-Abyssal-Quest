# Abyssal Quest — Birthday Ship

**For Jasmine.** Respect the Ocean. Home Reef is the gift.

## Launch (Mac)

```bash
cd /Users/carlboon/Documents/Rowblocks-Abyssal-Quest
npm install
npm run dev -- --host 0.0.0.0
```

Open: **http://127.0.0.1:5173/index-3d.html**  
(Port **3000** is often BoonMind Trader — if free, `npm run dev -- --port 5173` is safest. Smoke auto-detects the Abyssal Vite port.)

**Primary CTA:** **Dive Home Reef** (one tap). Use **More Levels** only for reefs 1–3.

## Launch (iPad — same Wi‑Fi)

1. Note Mac IP (`ipconfig getifaddr en0` or check Network)
2. On iPad Safari: **http://&lt;MAC-IP&gt;:5173/index-3d.html**
3. Landscape
4. Settings → Quality → **Medium (iPad)** if slow, then reload

## Production build

```bash
npm run build
```
